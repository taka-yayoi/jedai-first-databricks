# レベル3a: Lakeflow Designerでノーコードでパイプラインを作る

Lakeflow Designer は、ドラッグ&ドロップのキャンバスと自然言語で、コードを書かずにデータ変換を組める新しいETL機能です。Free Editionでデフォルト有効になっています。作ったワークフローは裏側で本番運用可能なコードに変換され、Unity Catalogでガバナンスされます。

経験者向けの「新機能キャッチアップ」としては、ここがいちばんの目玉です。SDP(Spark宣言型パイプライン)は中身が旧Delta Live Tablesなので目新しさは薄いですが、Designerはノーコード×AIで新しく、ノーコードとコードの橋渡しを体感できます。

公式ドキュメント: https://docs.databricks.com/ja/designer/

## 前提

- Unity Catalogが有効(Free Editionは標準で有効)
- サーバーレスコンピュートへのアクセス(Free Editionで利用可)

## 作るもの

`samples.nyctaxi.trips` を入力に、料金と距離が0より大きい行に絞り込み、曜日ごとに集計したテーブルを作ります。データはキャンバス上を左から右へ流れます。流れは「ソース → フィルタ → 集計 → 書き出し」です。

## ハンズオン手順

### 1. Visual data prepを作る

左メニューの「+新規」から「Visual data prep」を選びます。Designerが開き、データソースを追加するウェルカム画面が表示されます。見当たらない場合はワークスペース管理者に確認してください(Free Editionでは通常有効です)。

### 2. ソースを追加する

ウェルカム画面で「ソースオペレーターを選択」をクリックし、`samples.nyctaxi.trips` を選びます。キャンバスにSourceオペレーターが置かれます。

### 3. フィルタをつなぐ

オペレーターメニューからFilterオペレーターを追加します。Sourceオペレーターの右端の小さな丸から、Filterオペレーターの左端の丸へドラッグして接続します。条件は `fare_amount > 0 AND trip_distance > 0` です。

各オペレーターにはAIが生成した説明文が表示されます。説明文を日本語で書き換えると、オペレーターの設定がそれに合わせて再構成されます。ここがDesignerのAIネイティブなところです。

### 4. 集計する

Aggregateオペレーターをつなぎ、曜日ごとに乗車件数と平均料金を集計します。

曜日でグルーピングするには日付から曜日を取り出す必要があります。Transformオペレーターで列を追加するか、SQLオペレーターで `date_format(tpep_pickup_datetime, 'E')` を使うのが手軽です。やりたいことが固まっているなら、オペレーターパネルの検索に「曜日ごとの平均料金」のように意図を入れると、近いオペレーターが提案されます。

### 5. 途中結果をプレビューする

各オペレーターは、パイプライン全体を実行しなくても途中結果をプレビューできます。1ステップずつ「思ったとおりに変換されているか」を確かめながら組めるのが、コードとの大きな違いです。

### 6. Unity Catalogに書き出す

最後のオペレーターの結果を、テーブルとして `workspace.default` に書き出します。これでノーコードのパイプラインが完成です。

### 7.(発展)Genie Codeで自然言語編集する

Designerの中からGenie Codeを使うと、「曜日ごとの平均料金の列を足して」のように自然言語で変換を追加・修正できます。ノーコードのキャンバスと自然言語を併用する流れを試してみてください。

## 裏側を覗く(発展)

Designerが生成するのは本番運用可能なコードです。コードでパイプラインを書きたい経験者は `03a_lakeflow_pipeline_code.py` を見てください。中身はSDP(Spark宣言型パイプライン)で、Designerでビジュアルに作ったものと同じことをコードで表現しています。ノーコードとコードを見比べると理解が深まります。

## デモで見せたいポイント

- ドラッグ&ドロップでパイプラインが組み上がる様子
- オペレーターの説明文を自然言語で書き換えると設定が変わる挙動
- 途中結果のプレビュー
- 裏側で本番運用可能なコードが生成されていること

## 注意

- 実機のオペレーター名やUIの文言が手順と少し違う場合は、画面に合わせて読み替えてください。
