# レベル3a: Lakeflow Designerでノーコードでパイプラインを作る

Lakeflow Designer は、ドラッグ&ドロップのキャンバスと自然言語で、コードを書かずにデータ変換を組める新しいETL機能です。Free Editionでデフォルト有効になっています。作ったワークフローはUnity Catalogでガバナンスされ、Lakeflow Jobsでスケジュール実行できます。

経験者向けの「新機能キャッチアップ」としては、ここがいちばんの目玉です。SDP(Spark宣言型パイプライン)は中身が旧Delta Live Tablesなので目新しさは薄いですが、Designerはノーコード×AIで新しく、ドラッグ&ドロップと自然言語だけでデータ変換を組める体験が味わえます。

公式ドキュメント: https://docs.databricks.com/ja/designer/

## 前提

- Unity Catalogが有効(Free Editionは標準で有効)
- サーバーレスコンピュートへのアクセス(Free Editionで利用可)

## 作るもの

`samples.nyctaxi.trips` を入力に、料金と距離が0より大きい行に絞り込み、乗車地のzipコードごとに集計したテーブルを作ります。データはキャンバス上を左から右へ流れます。流れは「ソース → フィルタ → 集計 → 書き出し」です。

## ハンズオン手順

### 1. ビジュアルデータの準備を作る

左メニューの「+新規」から「ビジュアルデータの準備」を選びます。Designerが開き、データソースを追加するウェルカム画面が表示されます。見当たらない場合はワークスペース管理者に確認してください(Free Editionでは通常有効です)。

### 2. ソースを追加する

演算子(オペレーター)から「ソース」を選択、「既存を参照」クリックし、`samples.nyctaxi.trips` を選びます。キャンバスにソースオペレーターが置かれます。

### 3. フィルタをつなぐ

演算子メニューからフィルタオペレーターを追加します。ソースオペレーターの右端の小さな丸から、フィルタオペレーターの左端の丸へドラッグして接続します。条件は `fare_amount > 0 AND trip_distance > 0` です。

各オペレーターにはAIが生成した説明文が表示されます。説明文を日本語で書き換えると、オペレーターの設定がそれに合わせて再構成されます。ここがDesignerのAIネイティブなところです。

### 4. 集計する

集計オペレーターをつなぎ、乗車地のzipコード(pickup_zip)ごとに乗車件数と平均料金を集計します。

pickup_zipは元データにある列なので、集計オペレーターでグループ化する列に pickup_zip を選び、集計内容に件数と平均料金(fare_amount)を指定するだけで完成します。日付の変換のような派生列を作る必要がないので、ドロップダウンの選択だけでノーコードに組めます。ここが「コードを書かずに集計できる」というDesignerの気持ちよさを体感できるポイントです。

### 5. 途中結果をプレビューする

各オペレーターは、パイプライン全体を実行しなくても途中結果をプレビューできます。1ステップずつ「思ったとおりに変換されているか」を確かめながら組めるのが、コードとの大きな違いです。

### 6. Unity Catalogに書き出す

最後のオペレーターの結果を、テーブルとして `workspace.default` に書き出します。これでノーコードのパイプラインが完成です。

### 7.(発展)Genie Codeで自然言語編集する

Designerの中からGenie Codeを使うと、自然言語で変換を追加・修正できます。例えば「曜日ごとの平均料金を出して」と入力すると、日付から曜日を取り出す処理(`date_format`)まで含めて作ってくれます。

手作業だとひと工程かかる派生列の作成を、自然言語で丸ごと任せられるのがAIネイティブなところです。手順4ではあえて派生列のいらない pickup_zip で集計しましたが、「曜日ごと」のような一手間かかる集計こそ、Genie Codeに任せると差が見えます。ノーコードのキャンバスと自然言語を併用する流れを試してみてください。

## コードで書きたい場合(発展)

現時点では、Designerが内部で生成するコードをDesignerのUIから直接確認することはできません。コードでパイプラインを書きたい経験者は、同じ処理をSDP(Spark宣言型パイプライン)で書いた `03a_lakeflow_pipeline_code.py` を参照してください。Designerのノーコード操作と、コードで書いた場合の対応イメージをつかめます。

## デモで見せたいポイント

- ドラッグ&ドロップでパイプラインが組み上がる様子
- オペレーターの説明文を自然言語で書き換えると設定が変わる挙動
- 途中結果のプレビュー
- Genie Codeに曜日集計を自然言語で任せる流れ
